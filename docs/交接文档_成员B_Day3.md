## 2. 数据导入方式

```powershell
cd C:\Users\LENOVO\Desktop\拾光Agent\成员B_Day3_交付
python seed_data.py
```

- 仅使用 Python 标准库（sqlite3 / csv），无第三方依赖；
- 数据库文件 `shiguang_demo.db` 生成于脚本所在目录；
- 每次运行先 `DROP TABLE IF EXISTS` 再重建导入，**可安全重复执行**；

| longitude | REAL | 经度 |

| 字段 | 类型 | 说明 |
